# Security policy

This repository is a fork of [MeshAgent](https://github.com/Ylianst/MeshAgent). Its changes are in the Windows KVM
(DXGI capture, TurboJPEG tile encoding) and in the release workflows. The Windows x64 agent built from it is the default
agent of [kxd231/MeshCentral](https://github.com/kxd231/MeshCentral).

## Supported versions

Only the release that kxd231/MeshCentral currently pins in its `agents/agent-defaults.json` gets fixes.

## Reporting a vulnerability

Report it privately in this repository: **Security > Report a vulnerability**
(https://github.com/kxd231/MeshAgent/security/advisories/new). Please do not open a public issue.

A problem that also exists in the upstream agent should be reported to its maintainers as well, as described in the
[MeshCentral security policy](https://github.com/Ylianst/MeshCentral/security/policy).
